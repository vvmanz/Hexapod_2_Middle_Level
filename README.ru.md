# Hexapod_2_Middle_Level

**Координатор шестиногого робота: STM32F446RE, который по Ethernet говорит с компьютером через micro-ROS 2, управляет тремя моторными платами по двум шинам CAN и считает одометрию по IMU и датчику оптического потока.**

[English](README.md) | Русский

```
 компьютер с ROS 2             STM32F446RE · FreeRTOS · 180 МГц                моторные платы
┌────────────────────┐        ┌────────────────────────────────────┐          ┌─────────────┐
│ агент micro-ROS    │        │ rosTask       узел micro-ROS       │          │ платы 1 и 2 │
│ 192.168.10.2:33333 │◄──────►│ CAN           приём в IRQ, кадры   │◄─ CAN1 ─►│ плата 3     │
│                    │ UDP/IP │ odometryTask  MPU6050 + опт. поток │◄─ CAN2 ─►│ (Hexapod_1) │
│                    │        │ W5500 SPI1, 192.168.10.3           │          │             │
└────────────────────┘        └────────────────────────────────────┘          └─────────────┘
```

Это средний слой стека Hexapod. Вверх он говорит на ROS 2: публикует телеметрию всех шести приводов и принимает целевые
углы, настройки и коэффициенты регуляторов. Вниз упаковывает их в CAN-кадры для трёх
[моторных плат](https://github.com/<your-account>/Hexapod_1_Low_Level) и распаковывает их ответы. Параллельно он
оценивает положение робота по IMU и датчику оптического потока.

## Возможности

* **micro-ROS на FreeRTOS** (`ros_TASKS.c`): узел `STM32F446RET6` с автоматом состояний подключения: ожидание агента →
  создание узла, издателя и подписок → обработка; агент периодически пингуется, а после более чем 10 пропущенных пингов
  всё сворачивается и узел переподключается сам.
* **Ethernet-транспорт на W5500** по SPI1 (`transport_w5500.c`): собственный транспорт micro-XRCE-DDS на одном
  UDP-сокете со статическим адресом; свои аллокаторы (`custom_memory_manager.c`) держат micro-ROS внутри кучи FreeRTOS.
* **Две шины CAN на 1 Мбит/с** (`can_*_master.c`): CAN1 обслуживает платы 1 и 2, CAN2 — плату 3; приём в callback'ах
  прерываний с раздельными FIFO, счётчики ошибок и сторожевой таймер шины, перезапускающий обмен после 100 мс тишины.
* **Одометрия** (`odometry.c`, 100 Гц): MPU6050 по I2C1 с фильтром низких частот, фильтр ориентации Madgwick,
  определение неподвижности с автоматической оценкой смещения гироскопа по Z и заморозкой рысканья, а также модуль
  оптического потока и дальномера на USART1 (циклический приём по DMA, разбор кадров): его смещения масштабируются по
  высоте и поворачиваются в мировую систему координат, давая `x`, `y`, `φ` и их скорости.
* **FreeRTOS** (CMSIS-RTOS v2): `rosTask` (статический стек 32 КБ) и `odometryTask`, оба с приоритетом выше обычного; CAN
  обрабатывается в прерываниях, а не в задаче.
* **Проект STM32CubeMX** (`freeRTOS_microROS_F446RET6.ioc`): 180 МГц, CAN1, CAN2, CRC, I2C1, SPI1, USART1, FreeRTOS.

### Интерфейс ROS 2

Все топики — `std_msgs/Int32MultiArray`. Моторы нумеруются `плата_слот`: 1_1, 1_2, 2_1, 2_2, 3_1, 3_2.

| топик | направление | размер | содержимое |
|---|---|---|---|
| `vector` | MCU → ROS | 18 | на каждый мотор по порядку: угол, скорость, ток |
| `set_angles` | ROS → MCU | 6 | целевой угол каждого мотора |
| `set_other` | ROS → MCU | 27 | на каждую плату 9 значений: obstacle ×2, phase ×2, set-zero, тип системы ×2, ограничение скорости ×2 |
| `set_koeffs` | ROS → MCU | 42 | на каждый мотор 7 коэффициентов: угол `kp ki kd`, скорость `kp ki`, ток `kp ki` |

Состояние одометрии (`x`, `y`, `φ`, `vx`, `vy`, `ω`) считается на плате; топик `vector` несёт только телеметрию
приводов.

### CAN-кадры

| направление | ID | содержимое |
|---|---|---|
| MCU → плата *n* | `0x200` / `0x300` / `0x400` | целевые углы |
| | `0x201` / `0x301` / `0x401` | ограничения и прочие настройки |
| | `0x202`, `0x203` / `0x302`, `0x303` / `0x402`, `0x403` | коэффициенты регуляторов по моторам |
| плата → MCU | `0x101`, `0x103`, `0x105` | плата 1: токи, скорости, углы (CAN1) |
| | `0x100`, `0x102`, `0x104` | плата 2: токи, скорости, углы (CAN1) |
| | `0x501`, `0x503`, `0x505` | плата 3: токи, скорости, углы (CAN2) |

Каждый ответ несёт два значения `int32`, по одному на мотор платы.

## Требования

* STM32CubeIDE и ST-LINK;
* плата STM32F446RE с MPU6050 (I2C1), модулем оптического потока и дальномера (USART1), модулем W5500 (SPI1) и двумя
  CAN-трансиверами;
* компьютер с ROS 2 и агентом micro-ROS в той же подсети, что и MCU.

## Установка

```bash
git clone https://github.com/<your-account>/Hexapod_2_Middle_Level.git
```

1. **Статическая библиотека micro-ROS.** `libmicroros` в репозитории не хранится. Сгенерируйте её через
   [micro_ros_stm32cubemx_utils](https://github.com/micro-ROS/micro_ros_stm32cubemx_utils) под Cortex-M4F этого проекта.
   `microros_fix/Dockerfile` — патч образа сборщика (`micro_ros_static_library_builder:foxy`), обновляющий ключ
   apt-репозитория ROS, чтобы сборка снова работала.
2. Откройте папку в STM32CubeIDE (*File → Open Projects from File System…*), соберите и прошейте.
3. Дистрибутив ROS 2 агента micro-ROS должен совпадать с тем, под который собрана библиотека.

## Быстрый старт

Задайте компьютеру адрес, которого ждёт прошивка, запустите агент, затем включите MCU:

```bash
sudo ip addr add 192.168.10.2/24 dev <ваш-ethernet-интерфейс>
ros2 run micro_ros_agent micro_ros_agent udp4 --port 33333

ros2 topic list                    # vector, set_angles, set_other, set_koeffs
ros2 topic echo /vector            # телеметрия шести приводов: угол, скорость, ток
```

> `set_angles`, `set_other` и `set_koeffs` двигают настоящие ноги. Публикуйте в них только при поднятом над землёй
> роботе и с проверенными углами.

Адреса заданы в `Core/Src/transport_w5500.c`: MCU `192.168.10.3/24`, агент `192.168.10.2:33333`.

## Структура репозитория

```
Core/Src/ros_TASKS.c            задача micro-ROS: узел, топики, переподключение
Core/Src/transport_w5500.c      UDP-транспорт W5500 для micro-XRCE-DDS
Core/Src/microros_*.c, custom_memory_manager.c   аллокаторы и время для micro-ROS
Core/Src/can_TRANSMIT_RECEIVE_master.c   callback'и приёма CAN, сторожевой таймер шины
Core/Src/can_CONVERSION_master.c         упаковка углов, настроек и коэффициентов в кадры
Core/Src/odometry.c             MPU6050, фильтр Madgwick, оптический поток, поза
Core/Src/freertos.c             создание задач и приоритеты
Core/Src/w5500/, Core/Inc/w5500/   драйвер W5500
microros_fix/                   Dockerfile для сборщика библиотеки micro-ROS
freeRTOS_microROS_F446RET6.ioc  проект STM32CubeMX
Drivers/, Middlewares/          ST HAL, CMSIS, FreeRTOS (свои лицензии)
```
